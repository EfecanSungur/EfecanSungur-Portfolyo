# Efecan Sungur — Kişisel Portföy Sitesi

Kendi portföy sitemin kaynak kodu. Projelerimi, referanslarımı ve iletişim bilgilerimi sunan, yönetim paneli olan bir kişisel marka sitesi.

## Teknolojiler
- **ASP.NET Core 9 MVC** + Razor
- **Entity Framework Core** ile veri katmanı
- Elle yazılmış CSS ve sade JavaScript (framework yok)
- SEO: meta etiketleri, Open Graph görselleri, site haritası

## Özellikler
- Proje ve referans vitrini
- İçerikleri yönetmek için admin paneli
- Mobil uyumlu, hızlı açılan sayfalar

## Çalıştırma
```bash
git clone https://github.com/EfecanSungur/EfecanSungur-Portfolyo.git
cd EfecanSungur-Portfolyo
dotnet run --project EfecanSungur.Web
```

> Not: `appsettings.json` içindeki e-posta ve yönetici bilgileri boş bırakılmıştır; kendi değerlerinizi girmeniz gerekir.
